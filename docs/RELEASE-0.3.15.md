# Quota Widget 0.3.15

修正啟動時把 Codex `account/updated` 通知誤判成帳戶切換，避免清掉上次已記錄的百分比起點。只有新的額度回覆確認帳戶 ID 不同，才開始新統計區間；同帳戶重開後會由最近一次歷史額度下降開始，按完整本機 Token 紀錄計算總額。

相鄰、同來源及同額度週期的歷史百分比下降，即使跨程式工作階段，亦會按兩次下降之間的 Token 紀錄重建時間範圍和模型成本；Token 覆蓋缺口明確標示下限，沒有可用 Token 紀錄仍保留未知，不虛構金額。原始紀錄及既有帳戶資料不會修改。

每%用度表將起迄合併為單一 `UTC+08` 區間時間欄，並按 Sol、Luna、Astra 模型家族跨版本統計筆數和 USD，另列全部模型總額。懸停可看 Input、Cached、Output 等小計；不分模型版本或 reasoning 層級。

主視窗標題顯示 `每週額度 V 3.15`。設定新增 70–150% 字體大小選項，舊設定自動沿用 100%。
