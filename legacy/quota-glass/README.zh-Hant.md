# Quota Glass 使用說明

Windows 系統匣／macOS 選單列的小工具，用來查看 ChatGPT Work 剩餘配額。非 OpenAI 官方產品；程式碼採 MIT 授權。沒有分析追蹤、雲端後台或 API 金鑰輸入欄。

## 開始使用

1. 先安裝官方 Codex CLI。
2. 開啟 Quota Glass，選「連接現有登入」。首次開啟時，不會自動讀取帳戶。
3. 找不到 Codex 的話，可選擇官方安裝的執行檔。Windows 請選 `codex.exe`，不要選 npm 的 `.cmd`。
4. 尚未登入，可按「登入 ChatGPT」。先確認本機對話框，再親自在官方瀏覽器頁面完成授權。登入資料由 Codex 管理，不會放入這個工具或分享給朋友。
5. 關閉視窗會縮到系統匣／選單列；要完全退出，請用系統匣選單。

「示範模式」只有範例數字，不會連接帳戶。低配額通知預設關閉。

## 數字代表甚麼

- 剩餘百分比 = 100 − 來源回報的已用百分比。不會估出不存在的小數精度。
- 只有來源本身提供獨立配額，才可以分開顯示 Sol、Luna、Astra。否則保留來源名稱。
- 每分鐘消耗顯示最近最多 15 分鐘觀察到的「百分點／分鐘」，額外點數則獨立顯示「點數／分鐘」。最少要有一分鐘有效觀察。
- 預計用盡時間只是假設近期速度持續的估算。資料不足、重置、加點、來源中斷時，不會當成零消耗。
- 數字屬於帳戶整體，可能包含其他裝置、其他工作。不能只歸因於目前這個任務。

## 比較重置券與全局重置

程式會記錄配額上升／重置時間變動，來源一律先標「未知」。你可以自行標示為重置券、全局重置、排程重置，並補充模型／工作量備註，再匯出 CSV。

記錄的是牆鐘時間，不是實際運算時間；空檔會標示。工作內容、模型、推理強度都會影響消耗，所以「100% 用得較耐」本身不能證明絕對 token 配額不同。請不要在備註輸入帳戶、密碼或其他私人資料。

## 分享及安裝包

朋友應安裝自己的 Codex，使用自己的登入。只分享乾淨的原始碼壓縮檔或建置後的安裝包，不要分享 Codex 設定資料夾、auth.json 或個人應用程式資料。

已提供 Windows 與 macOS 的原生 CI 建置流程。這個版本沒有包含簽署／公證憑證；未簽署程式可能被作業系統攔截。請保留系統安全設定，確認來源可信後，使用系統支援的單一應用程式驗證方法。
